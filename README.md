# Посмотри в окно

Учебный проект Яндекс Практикума. Сайт показывает короткие видео с видами из окон разных городов. Ролики можно искать по названию города и времени суток. При выборе карточки ролик открывается в основном плеере.

## Что изменилось

### Вёрстка

- Собрана двухколоночная сетка по макету Figma. Слева расположены плеер и форма поиска, справа — заголовок и прокручиваемый список видео.
- Оформлены поле поиска, чекбоксы времени суток, кнопки и карточки. Для интерактивных элементов добавлены состояния наведения, нажатия и клавиатурного фокуса.
- Превью и видео вписаны в заданные размеры через `object-fit`. Длинные названия и описания сокращаются, чтобы сохранить размеры карточек.
- Прелоадеры размещены внутри плеера и списка, а сообщение об ошибке отображается в области плеера.

### Загрузка видео

- Обновлён адрес API, из которого загружаются карточки и ролики.
- Прелоадер убирается, когда ролик готов к воспроизведению. При ошибке загрузки появляется сообщение, после которого можно выбрать другую карточку.

## Запуск

Откройте `index.html` в браузере. Для загрузки карточек и видео требуется интернет.

## Как проверить работу

1. Откройте страницу и дождитесь загрузки карточек.
2. Выберите другую карточку и запустите ролик в плеере.
3. Найдите видео по городу и времени суток. Введите несуществующий город, чтобы увидеть сообщение о пустой выдаче.
4. Прокрутите список и нажмите «Показать ещё», если есть следующая страница.
5. Перейдите по элементам формы клавишей Tab и переключите чекбокс клавишей пробела.
